# 3D-print photos

[← Wind tunnel](../../README.md) · [Test photos](../../tests/photos/README.md)

20 supplied HEIC files, organized by visible subject rather than filename order. These photos document printed components and fabrication views; exact CAD-file matches, materials, dimensions, and print settings have not been verified.

JPEG previews are orientation-corrected, resized to at most 1400 pixels on the longest side, and saved without source EXIF metadata. Original HEIC files are preserved byte-for-byte under `originals/` using Git LFS. Original metadata remains in those files. Use the file page’s download option or `git lfs pull` after checking out this branch to retrieve originals. Capture dates and trial order are not inferred from filenames.
